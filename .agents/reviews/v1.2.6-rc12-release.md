Date: 2026-09-21 (Asia/Tehran)

## Scope and authority

RC12 supersedes immutable RC11 before installation. It contains only the reviewed redirect-header correction and the checkout-modal focus-restoration correction required by RC11's post-publication findings. It does not change identity resolution, registration policy, OTP purpose rules, native-login policy, the database schema, plugin settings, or server/site configuration.

The operator authorized report review, bug correction, GitHub delivery, and publication. This work did not install or replace the plugin on any site, change plugin options, touch a database/cache/service/theme, create checkout state, or activate the native-login gate. RC12 is a pre-release for separately authorized staging/canary acceptance; it is not stable/latest.
