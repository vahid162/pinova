# Pinova v1.3.0-rc3 release evidence

Date: 2026-09-23 (Asia/Tehran)

## Scope and predecessor

The immutable `v1.3.0-rc2` ZIP included first-party AI/development documents, SCSS, source maps, and vendored test/tool files. RC2 and its tag were preserved. RC3 changes only the packaging procedure and its regression gate; it does not change plugin runtime code, the database schema, or site configuration. The corrected ZIP contains 3,613 file entries, 87 fewer paths than RC2, and no added paths. The removed paths are development documents, source artifacts, and vendored tests/tools.

## Independent verification and handoff

All four public assets were downloaded again after publication. Both checksum files verified their targets; the locally computed SHA-256 of every asset matched the Release API digest. ZIP integrity passed, and `tools/check-package-content.sh` accepted the downloaded ZIP. The ZIP's `build-info.json` contains the exact merge commit, `pinova-release-zip` identity, and `v1.3.0-rc3` tag. The SBOM parses as SPDX 2.3. No first-party AI/development document, SCSS file, or source map remains in the ZIP.

RC3 is an immutable prerelease, not stable/latest and not an installed-site update. Production-like staging acceptance—including upgrade from the installed RC12 baseline, authentication/OTP and logging checks, read-only plugin-directory behavior, rollback, and the agreed observation window—remains outstanding. No site, database, plugin setting, or native-login gate was changed during publication. Do not use RC2 for a new installation; do not treat a GitHub source archive as the installable plugin.
