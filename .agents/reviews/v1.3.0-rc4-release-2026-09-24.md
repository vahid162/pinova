# Pinova v1.3.0-rc4 release evidence

Date: 2026-09-24 (Asia/Tehran)

## Scope and predecessor

This candidate contains the reviewed authentication and privacy fixes from [PR #50](https://github.com/vahid162/pinova/pull/50), including generic OTP responses and a final originating-IP/identifier block recheck before queued OTP creation. It also corrects the release SBOM inventory gate. The immutable RC3 tag and Release were preserved.

An independent file-by-file SHA-256 comparison of the downloaded RC3 and RC4 ZIPs found 3,613 entries in RC3 and 3,604 in RC4: one added, ten removed, and sixteen changed. The added file is the rate-limit exception; the removed files are vendored development files. Changed files include runtime PHP, Composer autoload manifests, readme, and build metadata. This comparison describes package contents, not staging acceptance.

## Independent verification and handoff

After publication, all four public assets were downloaded afresh. Both checksum files verified their targets, and locally computed SHA-256 digests of all four assets matched the Release API. `unzip -tq`, `tools/check-package-content.sh`, and `tools/check-sbom-content.sh` passed against the downloaded artifacts. The ZIP's `pinova/build-info.json` contains the exact merge commit, `pinova-release-zip` package identity, and `v1.3.0-rc4` release tag.

RC4 is an immutable GitHub prerelease, not stable/latest and not an installed-site update. The site owner will test it later. Staging/production acceptance, performance and authentication observation, and installation remain outstanding; no site, database, plugin setting, or native-login gate was changed during publication. Use the Release ZIP, not GitHub's automatic source archive, for installation.
