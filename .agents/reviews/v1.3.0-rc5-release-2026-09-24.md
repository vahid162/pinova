# Pinova v1.3.0-rc5 release evidence

Date: 2026-09-24 (Asia/Tehran)

## Scope and predecessor

RC5 corrects the five validated RC4 findings and the confirmed queued-worker and browser-test defects: spent OTP flows can be renewed, encrypted queue claims recover safely after a worker crash, privacy erasure accounts for active work and owned mobile aliases, checkout focus returns to a live opener after fragment replacement, and the release SBOM gate checks the complete Composer inventory. A PR review also found and corrected a native mobile-shaped username ownership edge case before merge. No database schema or public REST route was changed.

The immutable `v1.3.0-rc4` package was redownloaded and its SHA-256 verified as `ee668db186232b51f96bc93c34b0aabfb32554c3a57af03913b318a0c3bd4676`. Both RC4 and RC5 ZIPs contain 3,604 entries. An extracted-tree comparison found no added or removed paths and exactly seven changed files: `assets/js/pages/login-modal.js`, `build-info.json`, `readme.txt`, `src/Integrations/Wordpress/Privacy.php`, `src/Services/OTPService.php`, `src/Services/RateLimitService.php`, and `src/Services/UserService.php`. The RC4 tag and Release were not modified.

## Independent verification and handoff

All four public RC5 assets were independently downloaded after publication. Both checksum files verified their targets, and the locally computed SHA-256 of every asset matched the Release API digest. ZIP integrity and `tools/check-package-content.sh` passed. `tools/check-sbom-content.sh` matched all 44 installed Composer packages to the SPDX SBOM. The ZIP's `build-info.json` contains the exact merge commit, `pinova-release-zip` identity, and `v1.3.0-rc5` tag.

RC5 is an immutable prerelease, not stable/latest and not an installed-site update. Production-like staging, physical-mobile browser acceptance, upgrade from the installed RC12 baseline, authentication/OTP and logging checks, read-only plugin-directory operation, rollback, and the agreed observation window remain outstanding before production use. No site, database, plugin setting, or native-login gate was changed during publication.
