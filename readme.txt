ورود و عضویت با OTP و رمز عبور.

== Description ==

هویت: User ID؛ رمز عبور: ورود بومی وردپرس.

= امکانات =

* OTP از راه پیامک، ایمیل، پیام‌رسان بله و تماس صوتی
* ورود و ثبت‌نام وردپرس و ووکامرس با رابط واکنش‌گرا و دسترس‌پذیر
* مسدودسازی موبایل، ایمیل، نام کاربری و IP
* خروجی محدود Excel و VCF کاربران
* گزارش با Correlation/Flow ID و نگهداری محدود
* ابزارهای حریم خصوصی وردپرس

OpenSSL و cron منظم لازم است. پذیرش OTP دریافت قطعی نیست؛ خطای کانال در گزارش مدیر دیده می‌شود.
`wp pinova otp run` صف پینوا را محدود بررسی می‌کند؛ با WP-Cron غیرفعال، runner یک‌دقیقه‌ای با قفل سایت لازم است.

= تأیید موبایل =

پیوند حساب یا `[pinova_verify_mobile]` شمارهٔ همان حساب را تأیید می‌کند؛ حساب، نشست یا اختیار بازیابی نمی‌سازد. شمارهٔ قدیمی اثبات نیست؛ تغییر شماره یا کلید امضا تأیید را باطل می‌کند. کلیدهای wpForo/دکان پیش‌فرض خاموش‌اند؛ تأیید مدیر، مسدودیت، گروه‌ها و تأیید واقعی ایمیل حفظ می‌شوند. تبدیل بومی فروشنده به تأیید موبایل نیاز دارد؛ OTP نقش فروشنده نمی‌دهد. سازگاری مبتنی بر قابلیت است؛ wpForo مستقل کار می‌کند.

= تسویه‌حساب مجازی =

پیش‌فرض خاموش و فقط کلاسیک؛ سبد غیرخالیِ کاملاً مجازی می‌تواند نشانی، شرکت و یادداشت را حذف کند. تلفن، ایمیل، نام و اطلاعات ذخیره‌شده حفظ می‌شوند. مالیات محلی یا نیاز نامعلوم درگاه، فرم کامل را حفظ می‌کند؛ اعتبارسنجی درگاه تغییر نمی‌کند. Checkout Blocks پشتیبانی نمی‌شود.

= سرویس‌های خارجی و حریم خصوصی =

ارسال با فعال‌سازی مدیر و درخواست کاربر است. سرویس‌ها شمارهٔ مقصد، پیام/OTP، فرستنده یا شناسهٔ ربات و کلید حساب را دریافت می‌کنند؛ سرویس و قراردادش را در سیاست حریم خصوصی اعلام کنید.

* ملی پیامک: [قوانین](https://www.melipayamak.com/rules/)
* IPPanel/MaxSMS: [حریم خصوصی](https://ippanel.com/privacy/) و [شرایط](https://ippanel.com/terms/)
* پنل‌چی: [وب‌سایت](https://panelchi.com/)
* بله: [قوانین](https://bale.ai/terms)
* زحل، با شناسهٔ نمایندهٔ تماس صوتی: [شرایط](https://zohal.io/terms)
* پیامک ووکامرس فارسی، با درگاه منتخب مدیر: [صفحه افزونه](https://wordpress.org/plugins/persian-woocommerce-sms/)

خروجی حریم خصوصی: موبایل پروفایل، کد رخداد، زمان و Correlation ID مجاز؛ بدون OTP، رمز، Token، API Key، Fingerprint یا Context. Eraser تأیید را باطل، صف شمارهٔ جدید را لغو، متای موبایل و OTP موقت را حذف و پیوند شخصی گزارش را ناشناس می‌کند؛ واقعیت غیرهویتی باقی می‌ماند. خروجی مدیر Nonce، سقف و حذف دادهٔ حساس دارد. دفتر خصوصی تطبیق در Eraser پاک می‌شود؛ پرچم بازنشستگیِ بدون شماره برای جلوگیری از احیای نام مستعار می‌ماند.

OTP هفت روز پس از انقضا با cron پاک می‌شود؛ اختلال cron حذف را عقب می‌اندازد.

== Installation ==

1. پوشهٔ رسمی `pinova` را در `/wp-content/plugins/` نصب کنید.
2. افزونه را از مدیریت وردپرس فعال کنید.
