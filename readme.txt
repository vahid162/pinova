ورود و عضویت با OTP و رمز عبور.

== Description ==

= امکانات =

* OTP از راه پیامک، ایمیل، پیام‌رسان بله و تماس صوتی
* ورود وردپرس/ووکامرس با رابط واکنش‌گرا و دسترس‌پذیر
* مسدودسازی موبایل، ایمیل، نام کاربری و IP
* خروجی محدود Excel/VCF کاربران
* گزارش محدود، خط زمانی و سلامت صف با Correlation/Flow ID

OpenSSL و cron منظم لازم‌اند؛ پذیرش OTP تضمین دریافت نیست. خطای کانال در گزارش مدیر است.
ارسال فوری PHP-FPM اختیاری و خاموش است؛ صف و cron پشتیبان می‌مانند.
`wp pinova otp run` صف را محدود اجرا می‌کند؛ با WP-Cron غیرفعال، runner یک‌دقیقه‌ای و قفل سایت لازم‌اند.

= تأیید موبایل =

`[pinova_verify_mobile]` و پیوند حساب، شمارهٔ همان حساب را تأیید می‌کنند؛ حساب، نشست یا مجوز بازیابی نمی‌سازند. شمارهٔ قدیمی اثبات نیست؛ تغییر شماره/کلید امضا تأیید را باطل می‌کند. wpForo/دکان خاموش؛ تأیید ایمیل/مدیر، گروه و مسدودی حفظ می‌شوند. تبدیل بومی فروشنده تأیید موبایل می‌خواهد؛ OTP نقش فروشنده نمی‌دهد. سازگاری مبتنی بر قابلیت؛ wpForo مستقل.

= تسویه‌حساب مجازی =

خاموش و فقط کلاسیک؛ حذف نشانی، شرکت و یادداشت فقط برای سبد غیرخالیِ کاملاً مجازی. تلفن، ایمیل، نام و اطلاعات ذخیره‌شده می‌مانند. مالیات محلی یا نیاز نامعلوم درگاه، فرم کامل را حفظ می‌کند؛ اعتبارسنجی درگاه حفظ و Checkout Blocks پشتیبانی نمی‌شود.

= سرویس‌های خارجی و حریم خصوصی =

ارسال به انتخاب مدیر و درخواست کاربر است. سرویس‌ها مقصد، پیام/OTP، فرستنده یا شناسهٔ ربات و کلید حساب را می‌گیرند؛ قرارداد سرویس را در سیاست حریم خصوصی اعلام کنید.

* ملی پیامک: [قوانین](https://www.melipayamak.com/rules/)
* IPPanel/MaxSMS: [حریم خصوصی](https://ippanel.com/privacy/) و [شرایط](https://ippanel.com/terms/)
* پنل‌چی: [وب‌سایت](https://panelchi.com/)
* بله: [قوانین](https://bale.ai/terms)
* زحل، با شناسهٔ نمایندهٔ تماس صوتی: [شرایط](https://zohal.io/terms)
* پیامک ووکامرس فارسی، با درگاه منتخب مدیر: [صفحه افزونه](https://wordpress.org/plugins/persian-woocommerce-sms/)

خروجی حریم خصوصی فقط موبایل پروفایل، رخداد، زمان و Correlation ID است؛ بدون OTP، رمز، Token، API Key، Fingerprint و Context. Eraser تأیید/صف را باطل، متای موبایل، OTP و دفتر تطبیق را حذف و گزارش را ناشناس می‌کند؛ واقعیت غیرهویتی و پرچم بازنشستگیِ بدون شماره می‌مانند. خروجی مدیر محدود، با Nonce و پالایش اسرار است.

OTP هفت روز پس از انقضا با cron پاک می‌شود؛ اختلال cron حذف را عقب می‌اندازد. دیباگ: دامنه/مهلت/بودجه؛ نبود لاگ اثبات سلامت نیست.

== Installation ==

1. پوشهٔ `pinova` را در `/wp-content/plugins/` نصب و از پیشخوان فعال کنید.
