پینوا افزونهٔ ورود و عضویت وردپرس و ووکامرس با OTP، ایمیل و رمز عبور است.

== Description ==

ورود با موبایل، ایمیل، نام کاربری، رمز و OTP انجام می‌شود؛ هویت حساب WordPress User ID است و ورود با رمز از مسیر بومی وردپرس می‌گذرد.

= امکانات =

* OTP از راه پیامک، ایمیل، پیام‌رسان بله و تماس صوتی
* ورود و ثبت‌نام وردپرس و ووکامرس با رابط واکنش‌گرا و دسترس‌پذیر
* مسدودسازی موبایل، ایمیل، نام کاربری و IP
* خروجی محدود Excel و VCF کاربران
* گزارش عملیاتی با Correlation ID، Flow ID جریان OTP و نگهداری محدود
* Exporter، Eraser و متن پیشنهادی سیاست حریم خصوصی وردپرس

کد پیگیری از سرور می‌آید. پذیرش OTP، ارسال یا دریافت قطعی نیست؛ خطای کانال در گزارش مدیر دیده می‌شود. OpenSSL و cron منظم لازم است؛ دریافت را در Staging آزمایش کنید.
`wp pinova otp run` صف پینوا را محدود بررسی می‌کند؛ با WP-Cron غیرفعال، runner یک‌دقیقه‌ای با قفل سایت لازم است.

= تأیید موبایل =

کاربر با پیوند حساب یا `[pinova_verify_mobile]` شمارهٔ همان حساب را تأیید می‌کند؛ حساب، نشست یا مجوز بازیابی نمی‌سازد. شمارهٔ قدیمی اثبات مالکیت نیست؛ تغییر شماره یا کلید امضا، تأیید را باطل می‌کند. کلیدهای wpForo و دکان پیش‌فرض خاموش‌اند. تأیید مدیر، مسدودیت، گروه‌ها و واقعیت تأیید ایمیل حفظ می‌شوند. تبدیل فروشنده با فرم بومی همان حساب به تأیید موبایل نیاز دارد؛ OTP نقش فروشنده نمی‌سازد. سازگاری به قابلیت‌ها وابسته است؛ wpForo مستقل از ووکامرس و دکان کار می‌کند.

= تسویه‌حساب مجازی =

گزینهٔ عمومی ووکامرس پیش‌فرض خاموش است؛ فقط سبد غیرخالیِ کاملاً مجازی می‌تواند نشانی، شرکت و یادداشت را حذف کند. تلفن، ایمیل، نام و اطلاعات ذخیره‌شده حفظ می‌شوند. مالیات محل مشتری یا نیاز نامعلوم درگاه، فرم کامل را نگه می‌دارد. اعتبارسنجی درگاه تغییر نمی‌کند. فقط کلاسیک؛ Checkout Blocks در تنظیمات به‌عنوان پشتیبانی‌نشده اعلام می‌شود.

= سرویس‌های خارجی و حریم خصوصی =

ارسال با فعال‌سازی مدیر و درخواست کاربر انجام می‌شود. سرویس فعال، قرارداد پردازش و سیاست آن باید در سیاست حریم خصوصی سایت اعلام شوند.

* ملی پیامک: شماره مقصد، پیام/OTP، شماره فرستنده و Credential حساب. [قوانین](https://www.melipayamak.com/rules/)
* IPPanel/MaxSMS: شماره مقصد، پیام/OTP، شماره فرستنده و API Key. [حریم خصوصی](https://ippanel.com/privacy/) و [شرایط](https://ippanel.com/terms/)
* پنل‌چی: شماره مقصد، پیام/OTP، شماره مبدأ و API Key. [وب‌سایت](https://panelchi.com/)
* بله: شماره مقصد، پیام/OTP، شناسه ربات و کلید دسترسی. [قوانین](https://bale.ai/terms)
* زحل: شماره مقصد، OTP، API Key و شناسه نماینده تماس صوتی. [شرایط](https://zohal.io/terms)
* پیامک ووکامرس فارسی: شماره مقصد و پیام را به درگاه منتخب مدیر می‌سپارد. [صفحه افزونه](https://wordpress.org/plugins/persian-woocommerce-sms/)

خروجی حریم خصوصی: موبایل پروفایل، کد رخداد، زمان و Correlation ID مجاز؛ بدون OTP، رمز، Token، API Key، Fingerprint یا Context. Eraser تأیید را باطل، صف شمارهٔ جدید را لغو، متای موبایل و OTP موقت را حذف و پیوند شخصی گزارش را ناشناس می‌کند؛ واقعیت غیرهویتی باقی می‌ماند. خروجی جداگانهٔ مدیر Nonce، سقف و حذف دادهٔ حساس دارد.

== Installation ==

1. پوشهٔ رسمی `pinova` را در `/wp-content/plugins/` نصب کنید.
2. افزونه را از مدیریت وردپرس فعال کنید.
