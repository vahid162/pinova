پینوا افزونهٔ متن‌باز ورود و عضویت وردپرس و ووکامرس با OTP، ایمیل و رمز عبور است.

== Description ==

ورود با موبایل، ایمیل، نام کاربری، رمز و OTP انجام می‌شود؛ هویت حساب WordPress User ID است و ورود با رمز از مسیر بومی وردپرس می‌گذرد.

= امکانات =

* OTP از راه پیامک، ایمیل، پیام‌رسان بله و تماس صوتی
* ورود و ثبت‌نام وردپرس و ووکامرس با رابط واکنش‌گرا و دسترس‌پذیر
* مسدودسازی موبایل، ایمیل، نام کاربری و IP
* خروجی محدود Excel و VCF کاربران
* گزارش عملیاتی با Correlation ID، Flow ID جریان OTP و نگهداری محدود
* Exporter، Eraser و متن پیشنهادی سیاست حریم خصوصی وردپرس

کد پیگیری واقعی از سرور می‌آید؛ خطای بدون پاسخ شناسه ندارد.
پاسخ موفق درخواست OTP فقط پذیرش درخواست را نشان می‌دهد، نه ارسال یا دریافت قطعی کد. برای حفظ حریم خصوصی، خطای کانال به کاربر اعلام نمی‌شود؛ مدیر سایت می‌تواند گزارش عملیاتی محدود و پاک‌سازی‌شده را بررسی کند.
ارسال کد به OpenSSL و cron منظم نیاز دارد. در نصب تک‌سایتی، فرمان `wp pinova otp run` فقط صف پینوا را با سقف سه کار بررسی می‌کند؛ اجرای خارجی هر دقیقه و قفل cron سایت لازم است. دریافت کد را در Staging آزمایش کنید.

= تأیید موبایل حساب =

کاربر واردشده می‌تواند با پیوند حساب ووکامرس یا shortcode `[pinova_verify_mobile]`، شمارهٔ فعلی یا جدید را برای همان حساب تأیید کند. این جریان نشست یا حساب تازه و مجوز بازیابی رمز ایجاد نمی‌کند. شمارهٔ ثبت‌شدهٔ قدیمی به‌تنهایی اثبات مالکیت نیست؛ تغییر موبایل یا کلید امضای سایت تأیید قبلی را بی‌اعتبار می‌کند. تب یکپارچه‌سازی‌ها وضعیت وابستگی‌ها و کلیدهای مستقل و پیش‌فرض خاموش را نمایش می‌دهد. هماهنگی wpForo از تأیید موبایل برای عضویت جدید استفاده می‌کند؛ تأیید دستی، مسدودیت و تصمیم مدیر مستقل می‌مانند و وضعیت واقعی تأیید ایمیل تغییر مصنوعی نمی‌کند.

هماهنگی Dokan، ورود و تأیید موبایل را پیش از تبدیل همان حساب با فرم بومی «فروشنده شوید» الزامی می‌کند. تأیید فروشندگی و بررسی محصول مستقل می‌مانند. ورود با OTP نقش فروشنده ایجاد نمی‌کند؛ سفارش‌ها، شناسهٔ حساب و گروه‌ها و وضعیت عضویت انجمن هنگام تبدیل حفظ می‌شوند و شمارهٔ تماس فروشگاه به شناسهٔ ورود تبدیل نمی‌شود.

= سرویس‌های خارجی و حریم خصوصی =

ارسال فقط پس از فعال‌سازی کانال توسط مدیر و درخواست کاربر انجام می‌شود. مدیر سایت باید سرویس فعال، قرارداد پردازش داده و سیاست آن را در سیاست حریم خصوصی سایت اعلام کند.

* ملی پیامک: شماره مقصد، پیام/OTP، شماره فرستنده و Credential حساب. [قوانین](https://www.melipayamak.com/rules/)
* IPPanel/MaxSMS: شماره مقصد، پیام/OTP، شماره فرستنده و API Key. [حریم خصوصی](https://ippanel.com/privacy/) و [شرایط](https://ippanel.com/terms/)
* پنل‌چی: شماره مقصد، پیام/OTP، شماره مبدأ و API Key. [وب‌سایت](https://panelchi.com/)
* بله: شماره مقصد، پیام/OTP، شناسه ربات و کلید دسترسی. [قوانین](https://bale.ai/terms)
* زحل: شماره مقصد، OTP، API Key و شناسه نماینده تماس صوتی. [شرایط](https://zohal.io/terms)
* پیامک ووکامرس فارسی: شماره مقصد و پیام را به درگاه منتخب مدیر می‌سپارد. [صفحه افزونه](https://wordpress.org/plugins/persian-woocommerce-sms/)

خروجی حریم خصوصی فقط موبایل پروفایل و کد رخداد، زمان و Correlation ID مجاز را شامل می‌شود. OTP، رمز، Token، API Key، Fingerprint و Context لاگ صادر نمی‌شوند. Eraser تأیید موبایل را باطل، ارسال در انتظارِ شمارهٔ جدید را لغو و متای موبایل و OTPهای موقت را حذف و پیوند شخصی گزارش را ناشناس می‌کند؛ واقعیت غیرهویتی رخداد باقی می‌ماند.
خروجی رخداد مدیر از Exporter حریم خصوصی جداست؛ با Nonce، سقف محدود و حذف دادهٔ حساس ارائه می‌شود.

== Installation ==

1. پوشهٔ رسمی `pinova` را در `/wp-content/plugins/` نصب کنید.
2. افزونه را از مدیریت وردپرس فعال کنید.
